Project Name

PSUSphere

Short Description

PSUSphere is a Django-based student organization management system designed to manage colleges, academic programs, student organizations, students, and organization memberships.

Features
🏫 College Management – Manage college information.
📚 Program Management – Manage academic programs and their associated colleges.
🏢 Organization Management – Create and manage student organizations such as ACS and SITE.
👨‍🎓 Student Management – Store and manage student information.
🤝 Organization Membership Management – Record students' membership in student organizations.
🔐 Django Admin Panel – Manage the system's data through the Django administration interface.
🗃️ Database Management – Store and organize the application's data using Django models and migrations.
⚙️ Initial Data Generation – Generate sample organizations, students, and memberships using Faker.
